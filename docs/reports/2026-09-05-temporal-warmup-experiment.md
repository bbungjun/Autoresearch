# #105 날짜순 선행 이력과 최근 행동 피처 검증

## 문제

#103에서 최근 행동 5개 피처가 모든 학습 행에서 0이고 모델 분기에서도 사용되지 않았다.
기존 fixture는 평가 전 2일만 이력으로 갖고, 완전한 클릭 귀속을 위해 그중 첫날만 학습한다.
이 첫날보다 앞선 행동이 없어 7일 집계가 모두 cold-start 값이었다. 이는 피처 자체의
예측력이 없다는 증거가 아니므로 충분한 선행 이력을 제공해 다시 비교했다.

## 해결과 선택 근거

학습날 당일 행동을 넣는 방식은 날짜 계약을 깨뜨리므로 제외했다. 기존 7일 count와
30일 affinity를 모두 채우기 위해 30일 warm-up을 먼저 생성하고, 학습 대상 날짜를
그 뒤로 제한했다. 기존 v1 bytes/identity를 보존하는 opt-in v2를 사용한다.
노출과 click 생성 규칙을 그대로 유지해 인위적으로 최근 피처의 변동을 만들지 않았다.

| 역할 | KST 날짜 | 처리 |
| --- | --- | --- |
| 선행 이력 | 8월 2~31일 | 날짜순 생성, 피처에만 사용 |
| 학습 | 9월 1일 | warm-up 행 제외, 같은 seed의 15/10피처 학습 |
| 학습 label 귀속 확인 | 9월 2일 | 9/1 클릭 귀속용; 9/1 피처에는 들어가지 않음 |
| 평가 | 9월 3일 | 평가 이전 이력만 candidate에 공개 |
| 평가 label 귀속 확인 | 9월 4일 | Sealed Judge만 소비 |

사전 등록은 `44d648a`, 실행 코드는 `1a771e8`이다. World seed 10501/10502/10503,
training seed 301/302/303으로 3 world × 2 split × 3 seed × 2 arm = 36회 비교를 고정했다.
15피처는 #103의 인기도 제거 모델, 10피처는 최근 행동 5개를 추가 제거한 모델이다.
하이퍼파라미터와 E5 revision은 유지한다.

## 날짜 순서와 비유입 검증

RED에서는 신규 history profile·학습 선택이 없어 9건 실패했고, 기존 당일/미래 배제는
통과했다. GREEN 후 fixture/input/model/feature 관련 104건이 통과했다. 실제 v2 생성,
재사용·candidate 이력·학습 선택을 포함한 추가 관련 회귀는 116 passed, 2 skipped였다.
두 실행은 일부 테스트가 겹치므로 합산해 독립 테스트 수라고 주장하지 않는다.

통합 테스트에서 candidate를 Judge root 내부에 놓아 격리 검사에 거절된 테스트 배치를
형제 폴더로 수정했다. 검증 정책을 완화하지 않았다. 실제 producer 호출 순서 34일,
기본 v1 golden 입력 bytes, 생성된 v2의 재사용 identity, KST 7/30일 경계와 당일·미래
행 교란 무영향을 확인했다. 독립 리뷰에서 추가 P1/P2는 발견되지 않았다.
기존 #103의 world 10301 입력을 같은 runtime으로 다시 직렬화했을 때 descriptor hash도
`d01ec95224bb6dcca66bf5716eb18a8e7f60d207680a43977f22633f335c8f39`로 정확히 같았다.
이 확인은 입력 생성만 수행했으며 #103의 평가나 final 소비를 반복하지 않았다.

실험 전 별도 seed 10500의 candidate-safe 입력으로 시간 감사 경로를 확인했다.
학습 4,800행만 남기고 warm-up 144,000행을 제외했다. 학습 당일 이후 행동 10,800행을
제거한 뒤에도 전체 학습 피처가 동일했다. 최근 시청 시간은 2,728~3,613초의 4개 값으로
달라졌지만 click/view/like count는 7, total event count는 189로 모두 같았다.
이 점검은 metric이나 final을 소비하지 않았고, 아래 실험 수치와 구분한다.

### 실제 피처 값과 모델 사용

세 world의 선택된 학습 입력 4,800행 및 seed별 실제 fit 2,880행을 확인했다.
click/view/like count는 모두 7, total event count는 모두 189로 상수다.
최근 시청 시간은 각 world에서 min 2,728, max 3,613, 평균 3,207.75초,
모집단 표준편차 336.504초, 서로 다른 값 4개이며 null/0이 없다.
선행 7일/30일 완전성 flag는 학습·예측에서 모두 true였다.

최근 행동 포함 모델 18개 모두 최근 시청 시간을 사용했다. 평균 gain은 1,487.866,
평균 split 사용 횟수는 2,495.778이다. 나머지 최근 count 4개는 모두 gain/split=0이다.
이제 모델에 입력되는 값과 사용 사실은 확인됐지만, 사용 횟수를 성능 기여로 해석하지 않는다.

36개 예측 산출물을 paired 비교하면 점수는 43,200/43,200개가 달랐다. 점수 내림차순,
video ID 오름차순으로 정렬한 slate 전체 순서도 1,800개 중 1,799개에서 달랐다.
따라서 이번 동률은 **집계된 ranking 지표의 동률**이다. Binary click label이 있는 slate에서
일부 순서 변화는 지표 개선으로 이어지지 않을 수 있다. 개별 정답 순위는 추가로 열람하지 않았다.

### 시간·무결성 증거

- 3개 world에서 각각 34일을 날짜순 생성했다. 학습은 9/1의 4,800행이며 warm-up
  144,000행을 제외했다. Candidate history는 9/2까지만 게시됐다.
- 6개 split 감사 모두 학습 당일·이후 행동 10,800행을 제거해도 학습 피처가 같았다.
- 36개 학습 receipt의 선택 기간·피처 열·모델 hash·paired split 및 설정이 일치했다.
- 신규 snapshot 3개, evaluation ID 6개가 #16/#103과 겹치지 않았다. Final marker 3개,
  재소비 요청은 모두 거절됐고 기존 두 result 파일의 hash는 실행 전후 유지됐다.
- 학습 함수 누적 시간은 432.651초다. 피처 조립을 포함하므로 순수 fit 시간은 아니다.
  전체 779.014초에는 fixture 생성·입력 검증·감사·평가 등이 포함된다.
- E5 cache hit 864, miss 0, 새 inference 0회. Rule-based label을 사용했으며 LLM 호출은 없다.
- 원시 결과 SHA256:
  `ac12d96ddff7b711e6b83b225118e0435a2299ac41e8656242fd11f766b6cff3`.
- 원시 결과로 summary를 재계산해 일치를 확인했다. 원시 데이터/모델은 커밋하지 않는다.
- 실행: `python -m tools.run_recent_behavior`에 `--output`, `--model-dir`, `--cache-dir`,
  `--previous-result` 두 개를 전달했다. 완료된 #105는 재실행하지 않고 결과만 분석한다.


## 해석과 후속 결정

학습 시작 전에 이력을 갖추는 것은 피처를 학습할 수 있는 조건이다. 같은 값을 가진
count는 여전히 사용자를 구분하지 못하며, 분산이 있는 피처도 예측력은 실험으로 판정해야
한다. 사용자 키워드/영상 텍스트와 ID hash jitter 기반 label, 매일 사용자별 정해진 노출 수와
최대 1회 click 규칙이 실제 행동의 다양성을 대표하지 못한다.

**다음 결정:** 시간 분리 기능은 유지하고, 최근 행동의 ranking 기여는 미입증으로 기록한다.
15피처 기준선의 승격이나 10피처로의 일괄 교체는 하지 않는다. 다음 검증은 사용자별
행동 빈도와 관심 변화가 다양하게 나타나는 합성/LLM label 조건을 사전 등록해 수행한다.
먼저 생성 데이터의 count 분산과 관심 변화가 있는지 확인한 뒤 평가한다.
#103과 이번 실험은 날짜·이력·seed가 다르므로 절대 NDCG 차이를 warm-up의 인과 효과로
주장하지 않는다. 이번에는 production 모델/피처 계약을 바꾸지 않는다. 기존 final은 초기화하거나
재평가하지 않으며 실제 CTR, LLM relevance와 장기 폐루프는 #16의 남은 검증 범위다.
