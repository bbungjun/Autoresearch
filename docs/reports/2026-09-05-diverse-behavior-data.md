# #107 날짜순 행동 다양성 데이터 생성 실측

## 문제

#105에서 30일 선행 이력을 제공하자 최근 시청 시간은 모델에 사용됐지만 클릭·시청·
좋아요·전체 이벤트 count가 사용자 간 상수였다. 매일 모든 사용자에게 24개 노출과
1개 클릭을 만드는 기존 fixture 규칙으로는 행동 빈도가 다른 사용자를 검증하기 어려웠다.
이 작업의 목표는 최근 행동 피처를 구분할 수 있는 raw 데이터 확보이며 ranking 개선
실험은 아니다. Production 모델/피처 계약과 기존 fixture v1/v2를 유지한다.

## 해결과 선택 근거

기존 fixture 규칙을 바꾸면 앞선 실험의 재현성을 깨므로 별도의 `diverse-behavior-v1`
생성기를 추가했다. 사용자별 고정 활동 수준과 날짜별 결정적 난수로 접속, 노출량,
클릭, 시청 시간을 바꾼다. 일부 사용자는 이력 중간에 선호 카테고리를 바꾼다.
최초 사용자 metadata와 미래 잠재 상태를 분리하고, 학습일의 피처에는 전날까지의
행동만 쓰는 기존 계산기를 그대로 사용했다.

상위 행동 규칙은 합성 모델로 만들되 `ImpressionDraft` 이후에는 production event
확장과 writer를 재사용한다. 후보 수는 8/16/24이며 최대 1 click/slate와 click→view
연결을 유지한다. 입력 순서에 의존하지 않는 난수와 canonical 정렬, 고정 완료 시각으로
파일 재현성을 확보했다. 서로 다른 world의 event ID도 seed prefix로 구분한다.
LLM 호출보다 재현성과 낮은 비용을 우선한 선택이며 실제 사용자 대표성은 후속 과제다.

사전 계획 커밋은 `37e6205`, 실행 구현은 `cd2c7363aaca3918c113c998dfcd4542c1c5578e`다.
날짜와 seed 10701/10702/10703은 결과 관측 전에 고정했다.

| 역할 | KST 날짜 | 사용 범위 |
| --- | --- | --- |
| 선행 이력 | 2026-08-03~09-01 | 30일, 피처 계산용 |
| 학습 대상 | 2026-09-02 | 실제 노출 행을 선택해 피처 품질 검사 |
| 귀속 확인일 | 2026-09-03 | 학습일 피처에서 제외 |
| 후속 평가 예정 경계 | 2026-09-04 이후 | 이번에 생성·평가하지 않음 |

## 결과

**32일 × 3개 seed의 raw 데이터 생성과 품질 검증을 완료했다.** 총 168,548개 이벤트,
전체 생성·감사 53.970초다. 학습/예측은 실행하지 않았으며 GPU/LLM 호출과 final
평가는 0회다. 비용은 이 로컬 실행 시간으로 기록하며 외부 API 비용은 발생하지 않았다.

| seed | 사용자 | 이벤트 | 학습일 노출 | 데이터 품질 |
| --- | ---: | ---: | ---: | --- |
| 10701 | 200 | 56,714 | 1,632 | 통과 |
| 10702 | 200 | 53,569 | 1,528 | 통과 |
| 10703 | 200 | 58,265 | 1,448 | 통과 |

전체 사용자와 학습일 실제 노출에서 최근 5개 피처 각각 unique>=2, std>0, null=0을
확인했다. 이는 값의 다양성을 확인한 것이며 모델의 실제 fit 사용/성능 기여는 미검증이다.

### 전체 사용자 200명 기준 최근 7일 피처

표는 min~max (서로 다른 값 개수)다. 클릭과 view count가 같은 것은 production의
클릭→시청 연결 규칙 때문이다. 0인 사용자는 비활성/무클릭 행동의 결과이며 누락값이 아니다.

| 피처 | seed 10701 | seed 10702 | seed 10703 |
| --- | --- | --- | --- |
| 클릭 수 | 0~7 (8) | 0~6 (7) | 0~6 (7) |
| 시청 수 | 0~7 (8) | 0~6 (7) | 0~6 (7) |
| 시청 시간(초) | 0~5,477 (159) | 0~3,900 (155) | 0~4,049 (156) |
| 좋아요 수 | 0~6 (6) | 0~5 (6) | 0~5 (6) |
| 전체 이벤트 수 | 0~159 (85) | 0~153 (91) | 0~152 (88) |

seed 10701의 표준편차는 클릭/시청 1.591, 시청 시간 961.862초, 좋아요 1.126,
전체 이벤트 36.847이다. #105의 count 상수 상태에서 변화했다. 데이터 날짜·seed·
규칙이 다르므로 이 차이를 모델 성능의 인과 효과로 해석하지 않는다.

### 클릭 기록에서 관측한 관심 변화

전환 전후에 클릭이 모두 있는 사용자를 대상으로, 새 선호 카테고리 클릭 비율의
사용자별 전후 차이를 평균했다. Stable 사용자도 동일하게 정한 가상 경계에서 비교했다.
값은 비율 차이로, +0.9642는 약 +96.42%p다.

| seed | 전환 사용자 중 양쪽 관측 | 전환군 평균 변화 | 비전환군 평균 변화 |
| --- | ---: | ---: | ---: |
| 10701 | 95명 | +0.9642 | -0.0019 |
| 10702 | 88명 | +0.9488 | -0.0064 |
| 10703 | 92명 | +0.9700 | -0.0036 |

이 변화가 큰 것은 선호 카테고리 utility 0.6이 noise 최대 0.4보다 크기 때문이다.
선호 후보가 있으면 해당 카테고리에서 클릭을 선택하는 **의도적으로 강한 합성 규칙**이다.
실제 사용자처럼 관심이 변한다는 증거나 예측 난이도의 현실성을 입증한 결과가 아니다.

## 검증 근거와 보존

- 최초 신규 회귀는 9 passed, 1 failed였다. 실패는 날짜 범위 오류가 기존 `StageCError`로
  전달되는데 테스트가 다른 예외만 예상한 문제였다. 오류를 숨기거나 검증을 완화하지 않고
  실제 계약에 맞게 기대 예외를 수정했다.
- 관련 fixture 입력·피처·신규 데이터 회귀 79 passed. 독립 리뷰 권고를 반영한 엄격한
  timestamp 검사 추가 후 신규 회귀 14 passed. 중복이 있으므로 합산하지 않는다.
- 같은 seed의 32일 재생성에서 manifest와 event Parquet bytes가 일치했다. 다른 seed는
  다른 draft를 만들며 사용자·영상 입력 순서를 뒤집어도 결과가 같았다.
- 파일 누락·hash 변조·날짜 순서 변경·잠재 프로필 변경·동일 timestamp 귀속을 거절했다.
- 실측 3개 world에서 날짜 경계, ID 고유성, slate 크기, 선행 노출과 이후 클릭/시청/좋아요,
  metadata 관측일을 검사했다. 실제 파일 coverage가 확인된 뒤 7일/30일 완전성을 판정했다.
- 학습 당일·이후 행동을 제거해도 전체 학습 피처가 같았다. 임베딩은 이 감사에서만 상수를
  사용했으며 데이터에 저장하거나 모델 학습에 사용하지 않았다.
- 독립 구현·계약·실물 리뷰 P1/P2 없음. 리뷰어가 감사 함수를 재사용하지 않고 raw 로그에서
  최근 피처·관심 변화 통계를 재계산해 모든 필드 일치를 확인했다. World 간 포함
  168,548개 event ID가 모두 고유했다. 변경 Python Ruff와 `git diff --check` 통과.

출력은 `inputs/virtual_users.parquet`, 일별 `inputs/youtube_trending_kr`, `action_log`,
world별 `manifest.json`/`audit.json`, 전체 `summary.json`으로 구성된다.
원시 데이터는 커밋하지 않는다. 신규 경로 생성만 허용하고 완료 manifest 없는 디렉터리는
실패한 부분 산출물로 취급한다. 완료 데이터는 후속 작업에서 덮어쓰지 않는다.

각 manifest는 직접 기록한 3개 재사용 모듈 및 생성기 source hash, PyArrow 버전,
seed/날짜/파일 hash를 보존한다. 전이 의존성 전체를 hash한 것은 아니다.

| seed | manifest SHA256 |
| --- | --- |
| 10701 | `33f83133f73fc51ee09892d16e40555c2ced926f90ec0931a362fa011236bc79` |
| 10702 | `3ffc3ed5cd51084832aa4f11cc04009354c1c43273e3e6e2ad08482da69f9e14` |
| 10703 | `feb099b82b4a3962cbf36e4af80d3868a13e5e2ffcdd5519642c531e562866fc` |

전체 summary SHA256은 `e9d43b2cc2877f2a66d45dfbf777c3f6abefcb75e0a60853cff412e2be838fb9`다.

재현 명령은 `python -m tools.generate_behavior_data --output <새 경로>`다.
원래 완료 경로에 다시 실행하면 거절한다. 기존 #16/#103/#105 실험 경로나 final
marker를 이 도구에 입력하지 않으며 해당 실험의 재실행/재소비는 수행하지 않았다.

## 남은 한계와 다음 작업

데이터 준비는 완료했지만 새 모델의 개선 여부는 아직 모른다. 활동 빈도는 잠재 고정값이고,
click/view는 결합되어 있으며 최근 활동 자체가 후보 간 순위를 구분한다고 보장하지 않는다.
다음은 이 데이터에서 학습일 label·입력을 조립해 15/10피처 비교 조건을 고정하는 작업이다.
최종 평가에는 신규 seed/평가일과 봉인 snapshot을 사전 등록해 사용한다.
이번에 품질을 관측한 예약 사용자와 원시 manifest를 미관측 final로 재포장하지 않는다.
후속 모델 평가는 성능 향상뿐 아니라 무효 결과도 기록해야 한다.
