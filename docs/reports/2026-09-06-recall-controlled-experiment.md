# #117 Recall@10 원인 후보 통제 실험

## 결론

**사전 등록한 통제 실험과 신규 봉인 평가를 수행했으며, 최종 후보는 채택하지 않는다
(`not_supported`).** 영상별 선호 피처는 신규 final에서 Recall@10을
0.815790→0.973156으로 높였으나 Brier가 0.032651→0.032752로 악화했다.
개선 폭이 큰 ranking 지표만 골라 판단하거나, 결과를 본 뒤 무악화 기준을 완화하지 않았다.

이는 유효한 평가에서 채택 조건을 충족하지 못한 결과다. 표본 부족·실행 오류와 구분한다.
서빙 배포와 production 모델 승격은 수행하지 않았다.

## 문제와 통제 설계

#113의 15대10피처 비교에서 Recall@10이 하락했고, #115의 저장 validation 분석은
top10 이탈137/진입107이 그 하락을 구성함을 확인했다. 하지만 과적합, binary 학습목표,
영상별 선호정보 부족, 작은 학습표본 가운데 어느 개입이 효과적인지는 미확인이었다.

실험 전에 [spec](../archive/specs/2026-09-06-recall-controlled-experiment.md)과 실행 계획을
커밋 `21fa703`으로 등록했다. 독립 검토에서 raw margin 보정 입력을 더 명확히 고정했고,
실제 실행 코드는 `8262d0e`다. 완료 후 spec/plan을 archive로 옮기고 실행기의 spec 경로만
갱신했다. 해당 문서 정리 후 실험을 재실행하지 않았으며, 실행 당시 코드·계약은 저장 commit과
preflight hash로 확인한다. 기존 #109 학습 bundle과 #111 validation만 개발에 사용했다.
기존 final 정답·예측은 평가에 사용하지 않았으며 데이터·소비 marker의 bytes를 보존했다.

기존 노출 행별 분할은 같은 slate를 나눌 수 있으므로 모든 신규 arm을 **사용자 단위
60% fit/20% calibration/20% reserve**로 통일했다. vocabulary는 기본 fit만 사용하며
미지 범주는 결측으로 처리했다. ranker에는 slate별 연속 행과 검증된 group 크기를 전달했다.
모든 binary를 단위 가중치로 고정해 LambdaRank와 class weighting 변경이 섞이지 않게 했다.
따라서 #113의 가중 binary 결과와 직접 비교하는 실험이 아니라 **새 공통 protocol에서의
단일요인 개입 비교**다.

공통 모델은 LightGBM 200trees, learning rate0.05, num_leaves31,
min_child_samples20, 단일 스레드, early stopping·튜닝·다운샘플링 없음이다.
모든 모델의 raw margin으로 같은 calibration 사용자 집합에서 양의 기울기 sigmoid를
1회 fit했다. 순위/AUC/AP는 raw score, LogLoss/Brier는 보정 확률을 사용했다.
ranker 점수에 단순 sigmoid를 씌워 확률 지표를 비교하지 않았다.

| arm | 변경한 요소 | 모델/보정 fit |
|---|---|---:|
| baseline15 | 공통15피처 대조군 | 6/6 |
| reference10 | 최근 행동5열만 제거한 참고 대조군 | 6/6 |
| shallow | num_leaves31→7만 변경 | 6/6 |
| ranker | objective를 LambdaRank로 변경, gain[0,1], truncation10 | 6/6 |
| preference | 후보영상 카테고리의 과거7일/30일 클릭 비율2열 추가 | 6/6 |
| larger | reserve 사용자를 fit에 추가, 60%→80% | 6/6 |

3world ×2seed(401/402)의36모델·36보정기, 총72학습시도다.
가설별 후보는1종이며 90회 상한의 나머지18회를 추가 탐색에 사용하지 않았다.
선호 피처는 요청일 KST 자정 이전의 관측 클릭과 시점 metadata만 사용했고 잠재 profile을
입력으로 사용하지 않았다. 표본 증가군도 같은 날짜·생성 분포·기본 vocabulary·calibration을
공유하여 시간 변화와 전처리 변화의 혼입을 피했다.

봉인한 후에만 새 사용자 cohort11701/11702/11703을 생성했다. 각 cohort는 validation200명,
final800명이지만 신규 validation은 선택이나 채점에 사용하지 않았다. 기존 행동 생성 규칙과
8/3 anchor·9/4 평가·9/5 귀속 tail을 유지한 합성 데이터이며, 미래 실제 관측을 주장하지 않는다.
추가 metadata 감사에서도 #16/#103/#105의9개 기존 cohort 사용자1,800명과 신규 사용자3,000명
사이에 중복이 없었다. 사용자ID 생성 규칙만 대조했으며 기존 final 정답은 읽지 않았다.

## 신규 final과 채택 판단

cohort별 한 번씩 총3회 소비했다. 각 cohort의 baseline15/reference10/preference ×2seed,
총6개 예측을 모두 봉인한 후 정답을 읽어 채점했다. 개발에서 학습한 모델/보정기를 재사용했고
재학습·재선택·재채점은 없었다. 신규 final18개, 개발36개로 총54개 평가 관측이다.

| 지표 | baseline15 | preference | Δ(후보−기준) | 조건 |
|---|---:|---:|---:|---|
| Recall@10 | 0.815790 | 0.973156 | +0.157366 | 통과 |
| NDCG@10 | 0.434282 | 0.616149 | +0.181867 | 통과 |
| NDCG@24 | 0.480387 | 0.622744 | +0.142357 | 통과 |
| grouped ROC-AUC | 0.644217 | 0.846083 | +0.201866 | 통과 |
| PR-AUC(average precision) | 0.057348 | 0.120678 | +0.063330 | 통과 |
| 보정 LogLoss | 0.145782 | 0.128173 | −0.017609 | 통과 |
| 보정 Brier | 0.032651084 | 0.032751523 | **+0.000100439** | **미통과** |

Recall 개선은6/6쌍·3/3world에서 관측됐다. Brier는 낮을수록 좋으며 평균 악화는
사전 등록된 무악화 조건을 위반한다. 따라서 **preference는 ranking 효과가 관측됐지만
전체 채택 조건은 미달**이다. Brier 악화가 작은지, 보정 표본의 변동 때문인지 사후 추측해
조건을 무시하지 않는다. Brier 악화의 구체적 원인은 이번 실험에서 확인하지 않았다.

참고10피처 final Recall은0.825364(기준 대비+0.009574)이지만 PR-AUC가
0.057348→0.055963으로 악화했다. 이 대조군을 결과 확인 후 대체 후보로 승격하지 않았다.

## 확인 사실과 원인 가설의 경계

| 가설 | 이번에 확인한 사실 | 확인하지 못한 주장 |
|---|---|---|
| 모델 복잡도가 높아 Recall이 낮다 | leaves7 개입은 개발 Recall을 개선하지 못했다 | 모든 정규화·모델 복잡도 문제가 배제됐다는 주장 |
| binary 목표가 Recall을 떨어뜨린다 | 고정 LambdaRank 개입은 개발 Recall을 개선하지 못했다 | 모든 순위 학습 또는 Recall 직접최적화가 무효라는 주장 |
| 영상별 선호정보가 부족하다 | 관측 카테고리 선호2열이 개발·신규final ranking을 일관되게 개선했다 | #113 하락의 유일한 원인, 실제 사용자 CTR 개선, 전체 채택 성공 |
| 표본이 작아 Recall이 낮다 | 같은 날짜 nested60→80% 표본 증가가 개선하지 못했다 | 훨씬 큰 학습셋이나 다른 수집 분포도 효과 없다는 주장 |

표본 증가의 실제 fit행은 world/seed별 824~1,024→1,112~1,360행,
fit slate는55~64→74~86개였다. calibration은 각 pair에서272~368행으로 동일했다.
한정된 크기 증가만 검증했으며 보편적인 학습 곡선을 얻은 것은 아니다.

합성 생성기의 선택 효용은 카테고리 선호를 직접 사용한다. 관측 클릭에서 카테고리 선호를
추정한 개입의 효과는 이 합성 분포에서의 유용성을 지지한다. 실제 사용자의 선호 변화,
장기 폐루프, 온라인 실험 결과로 확대 해석하지 않는다.

## 수행·미수행

실험 사전등록, 네 가설의 개별 개발 비교, 후보 고정, 신규final 평가, 채택 판정을 수행했다.
복잡도·ranker·larger의 신규final 평가는 사전 선택 규칙에 따라 수행하지 않았다.
조합 후보, 추가 후보, 추가seed, 보정법 재튜닝, 실제 사용자 실험, 배포·production 승격은 수행하지 않았다.
이 결과의 다음 연구 과제는 **별도 사전등록과 별도 신규평가**를 전제로 한 확률 보정 안정성 검증이다.
이번 final을 재사용하거나 채택 기준을 변경하는 후속 작업은 포함하지 않는다.
