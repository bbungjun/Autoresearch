# #119 실행 계획

상태: 실제 실험·관련 회귀·독립 코드/결과 감사 완료, supported.
구현 계획을 완료해 archive로 보존하며 CI·머지 상태는 연결 PR에서 확인한다.
실험 결과를 보기 전에 아래 순서를 고정했다.

1. #117 저장 모델·입력 pin과 독립 보정 사용자 계약을 구현한다.
2. Brier 양성/음성 기여·구간진단·6쌍 고정 판정 및 예산/봉인 실행기를 연결한다.
3. 변경 관련 회귀와 독립 코드 리뷰를 통과한 깨끗한 commit에서 12보정·24개발 평가를 실행한다.
4. 모델/보정/조건 봉인 후 신규 cohort 3개에서 24final 평가·3단일소비를 수행한다.
5. 저장 지표만 독립 재집계하고 원본 보존·실측·한계·미수행을 보고서에 기록한 뒤 CI·머지한다.

완료는 결과의 긍정 여부와 별개다. 실패/표본부족이면 수행하지 못한 단계를 명시하고
계획된 성공 실행으로 포장하지 않는다. final 재평가·실패fit 재시도는 하지 않는다.

구현 검증: 관련 4개 테스트 파일 109 passed, 전체 Ruff·diff check 통과.
독립 리뷰의 과거 cohort manifest pin/평가 ID 제외 목록 P2를 수정했으며,
리뷰어가 새 테스트 20 passed와 미해결 P1/P2 없음을 확인했다.
실제 실행: 모델 fit0·보정 fit12·개발24·신규final24·3claim, 173.810초.
독립 결과 감사에서 저장48예측·지표·봉인·이전1152파일 보존과 supported 판정이 일치했다.
학습 전 기동 오류 2건과 복구, 한계는 실측 보고서에 남겼다.
